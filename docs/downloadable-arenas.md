# زمین‌های قابل دانلود (GitHub Arenas)

این قابلیت همهٔ ۱۶ زمین اولیهٔ بازی را در APK نگه می‌دارد. زمین‌های اختیاری فقط هنگام فشردن دکمهٔ **بررسی زمین‌های جدید** در مرحلهٔ انتخاب نقشه از GitHub دریافت می‌شوند. سپس کاربر هر زمین را جداگانه دانلود می‌کند. فایل JSON و پس‌زمینهٔ SVG یا WebP در حافظهٔ محلی گوشی ذخیره می‌شوند و زمین دانلودشده بدون اینترنت نیز قابل بازی است.

## زمین‌های دانلودی موجود

در حال حاضر پنج زمین اختیاری در `public/downloadable-arenas/catalog.json` فهرست شده‌اند:

| زمین | شناسه | تفاوت در مبارزه |
| --- | --- | --- |
| جنگل مه‌آلود | `extra-forest` | پرش بلندتر و سکوهای جنگلی |
| کویر سرخ | `extra-desert` | سکوی لغزنده در فضای کویری |
| قله یخی | `extra-glacier` | کف و سکوهای یخی، پرش بلندتر، کوهستان برفی |
| آتشفشان سوزان | `extra-volcano` | زمین دوپاره و شکاف سقوط میان میدان |
| بام‌های نئونی | `extra-neon-city` | سکوهای متحرک، نوارهای نقاله و حرکت سریع‌تر |

هر پنج زمین اکنون در **نسخهٔ ۲** دارای یک تصویر جدید `background.webp` با ابعاد 1600×900 هستند. فایل‌های SVG قدیمی در مخزن باقی مانده‌اند، اما فایل JSON نسخهٔ ۲ از WebP استفاده می‌کند. بازیکنانی که پیش‌تر نسخهٔ ۱ این زمین‌ها را دانلود کرده‌اند، با «بررسی زمین‌های جدید» گزینهٔ **به‌روزرسانی** را می‌بینند. استفاده از WebP به نسخه‌ای از بازی نیاز دارد که قابلیت WebP را داشته باشد؛ نسخه‌های قدیمی‌ترِ صرفاً SVG نمی‌توانند فایل WebP نسخهٔ ۲ را نصب کنند.

## انتشار زمین جدید بدون تغییر APK

۱. در همین مخزن یک شاخهٔ جدید بسازید و پوشهٔ `public/downloadable-arenas/new-place/` را اضافه کنید.

۲. یک `arena.json` مطابق نمونه‌های `forest/arena.json` و `desert/arena.json` ایجاد کنید. `id` باید شکل `extra-new-place` داشته باشد. تنظیمات معتبر عبارت‌اند از `platforms` (حداکثر ۲۴ سکو)، `spawnX`، `gravity`، `fallLimit`، `speedMultiplier`، `jumpMultiplier`، `movingPlatforms` و رنگ‌ها و سبک تصویری در `theme`. قالب JSON برای اجرای کد یا افزودن مکانیک جدید استفاده نمی‌شود.

۳. یکی از دو نوع تصویر پس‌زمینه را اضافه کنید و نام آن را در فیلد `background` از `arena.json` مشخص کنید:

   - **SVG:** مقدار `"background": "background.svg"`؛ فایل مستقل با نسبت 16:9 و ابعاد پیشنهادی 1600×900. استفاده از `script`، `foreignObject`، `image`، `use`، event handler و پیوند خارجی ممنوع است. حجم مجاز SVG حداکثر **۶۰ کیلوبایت** است.
   - **WebP:** مقدار `"background": "background.webp"`؛ فایل WebP واقعی با حجم حداکثر **۳۸۴ کیبی‌بایت (393,216 بایت)** و ابعاد حداکثر **2560×1440** پیکسل. پیشنهاد برای پس‌زمینهٔ بازی **1600×900** با کیفیت متعادل است. فقط WebP ثابت (غیرمتحرک) مجاز است؛ دریافت باینری با بررسی سربرگ RIFF/WebP، ابعاد و رمزگشایی تصویر انجام می‌شود. فایل پس از نصب در همان حافظهٔ آفلاین بازی ذخیره می‌شود.

   نمونه ساخت WebP از یک تصویر PNG با ابزارهای طراحی یا با فرمان زیر:

   ```bash
   cwebp -q 76 -m 6 -resize 1600 900 background.png -o background.webp
   ```

   اگر WebP بیشتر از سقف حجم بود، کیفیت را کاهش دهید یا جزئیات عکس را کمتر کنید. قبل از انتشار، نمای تصویر را روی موبایل بررسی کنید. **برای نمایش پس‌زمینهٔ WebP، کاربران باید نسخه‌ای از APK را داشته باشند که این قابلیت را پشتیبانی می‌کند؛ APKهای قدیمی فقط SVG را می‌شناسند.** تصاویر SVG قدیمی در مخزن حفظ شده‌اند تا فایل‌های قبلی قابل بازیابی باشند.

۴. یک ورودی به `public/downloadable-arenas/catalog.json` اضافه کنید:

```json
{"id":"extra-new-place","version":1,"names":{"fa":"زمین جدید","en":"NEW ARENA"},"path":"new-place/arena.json"}
```

۵. تغییرات را در شاخهٔ `main` ادغام کنید؛ بازیکنان با زدن «بررسی زمین‌های جدید» فهرست تازه را خواهند دید. برای به‌روزرسانی زمین موجود، شمارهٔ `version` را هم در فهرست و هم در `arena.json` افزایش دهید.

## ملاحظات

- آدرس دریافت به `raw.githubusercontent.com/abolfazl260/doodlegame/main/public/downloadable-arenas/` محدود شده است.
- حداکثر ۸ زمین اختیاری هم‌زمان روی دستگاه نصب می‌شوند تا فضای ذخیره‌سازی کنترل شود. فایل WebP پس از دانلود به صورت Base64 در فضای ذخیره‌سازی محلی نگهداری می‌شود؛ اگر سهمیهٔ دستگاه پر شود، دانلود با خطا پایان می‌یابد و فایل قبلی حفظ می‌شود.
- بازی هرگز از فایل‌های دانلودشده JavaScript یا کد اجرایی اجرا نمی‌کند. ابعاد زمین، شناسه‌ها، رنگ‌ها، SVG و سربرگ/اندازه WebP بررسی می‌شوند و تصویر قبل از ذخیره رمزگشایی می‌شود.
- اگر GitHub در دسترس نباشد، ۱۶ زمین اصلی و زمین‌های دانلودشده بدون وابستگی به اینترنت اجرا می‌شوند.
- پاک‌کردن داده‌های برنامه ممکن است زمین‌های دانلودی را هم حذف کند؛ پس از آن باید مجدداً دانلود شوند.
- زمین جدید فقط می‌تواند از مکانیک‌های پیاده‌سازی‌شده در موتور فعلی استفاده کند. اضافه‌کردن نوع مانع یا قانون فیزیکی کاملاً جدید به انتشار نسخهٔ جدید APK نیاز دارد.
