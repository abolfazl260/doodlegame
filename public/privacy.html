DoodleGame Privacy Policy

Last updated: October 6, 2026

DoodleGame does not collect or share personal or sensitive user data. The game has no user accounts, analytics, advertising, crash-reporting service, cloud save, or DoodleGame telemetry backend.

Developer and contact

This policy applies to the DoodleGame application and the DoodleGame project maintained at github.com/abolfazl260/doodlegame. For privacy questions or requests, use the public privacy contact mechanism at DoodleGame GitHub Issues.

Data stored on your device

DoodleGame stores only the selected language preference in the browser/WebView local storage so the interface can remember English or Persian. Current match and weapon-upgrade state are held locally in memory for the current game session. This information is not sent to DoodleGame servers or third parties.

Data collection and sharing

The current application does not collect or share personal information, device identifiers, precise or approximate location, contacts, photos, videos, audio, financial information, health information, messages, browsing history, app activity, or gameplay telemetry.

Android network permission

The Android package includes the INTERNET permission used by the Capacitor/WebView application runtime. The current DoodleGame code does not use that permission to transmit gameplay or personal/sensitive user data to a DoodleGame backend.

Retention and deletion

The local language preference remains on the device until app/site data is cleared or DoodleGame is uninstalled. Session gameplay state is discarded when the session/app process ends. DoodleGame does not maintain a server-side account, profile, cloud save, or user-data record that requires a server-side deletion request.

Public policy hosting

This page contains no analytics scripts, advertising scripts, cookies set by DoodleGame, or remote assets. It is hosted through GitHub Pages. If you visit this web page, GitHub's hosting infrastructure may process ordinary connection information under GitHub's own privacy terms. The full DoodleGame privacy policy is also available inside the application without needing to open this web page.

Changes

If DoodleGame later adds accounts, analytics, advertising, cloud services, or other data collection/sharing, this policy and the Google Play Data Safety declaration will be updated before that version is released.

سیاست حریم خصوصی DoodleGame

آخرین به‌روزرسانی: ۶ اکتبر ۲۰۲۶

DoodleGame هیچ داده شخصی یا حساس کاربر را جمع‌آوری یا با شخص ثالثی به‌اشتراک نمی‌گذارد. بازی حساب کاربری، تحلیل‌گر، تبلیغات، سرویس گزارش crash، ذخیره ابری یا سرور تله‌متری DoodleGame ندارد.

توسعه‌دهنده و راه ارتباطی

این سیاست مربوط به برنامه DoodleGame و پروژه DoodleGame در GitHub است. برای پرسش‌های حریم خصوصی می‌توانید از Issues پروژه استفاده کنید.

داده‌های محلی دستگاه

فقط زبان انتخاب‌شده برای رابط کاربری در localStorage مرورگر/WebView ذخیره می‌شود. وضعیت مبارزه و ارتقای سلاح‌های دور فعلی فقط در حافظه همان نشست بازی قرار دارد. این اطلاعات به سرور DoodleGame یا شخص ثالث ارسال نمی‌شود.

جمع‌آوری و اشتراک‌گذاری

نسخه فعلی اطلاعات شخصی، شناسه دستگاه، موقعیت مکانی، مخاطبین، عکس و ویدیو، صدا، اطلاعات مالی یا سلامت، پیام‌ها، تاریخچه مرور، فعالیت برنامه یا تله‌متری gameplay را جمع‌آوری یا به‌اشتراک نمی‌گذارد.

مجوز اینترنت اندروید

بسته اندروید مجوز INTERNET مربوط به runtime مبتنی بر Capacitor/WebView را دارد؛ اما کد فعلی DoodleGame از این مجوز برای ارسال داده gameplay یا اطلاعات شخصی/حساس به backend بازی استفاده نمی‌کند.

نگهداری و حذف

تنظیم زبان تا زمانی که داده برنامه/سایت پاک شود یا برنامه uninstall شود روی دستگاه باقی می‌ماند. وضعیت نشست بازی با پایان نشست/فرآیند برنامه از بین می‌رود. DoodleGame حساب، پروفایل، cloud save یا رکورد کاربری سمت سرور ندارد که نیازمند درخواست حذف سروری باشد.

تغییرات آینده

اگر در آینده حساب کاربری، analytics، تبلیغات، سرویس ابری یا جمع‌آوری/اشتراک‌گذاری داده اضافه شود، این سیاست و Data Safety گوگل پلی پیش از انتشار آن نسخه به‌روزرسانی خواهند شد.
